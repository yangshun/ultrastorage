## One familiar API. A lot less housekeeping.

Create one shared instance, then read and write real JavaScript values without manual serialization.
Add expiration and subscriptions only where you need them.

```ts
import { createStorage } from 'ultrastorage';

const storage = createStorage({ prefix: 'editor' });

storage.setItem(
  'draft:post-42',
  {
    title: 'Introducing ultrastorage',
    updatedAt: new Date(),
    tags: new Set(['release', 'docs']),
  },
  { ttl: 86_400_000 },
);

storage.subscribe('draft:post-42', refreshPreview);
```
